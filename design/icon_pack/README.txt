RhoCoo icon package

launcher/: resized concept #2 images (square with purple background)
android/mipmap-*: launcher icons at standard density sizes
android/drawable-*: white-on-transparent notification small icons at standard density sizes
notification/: additional notification icon sizes
notification_icon.svg: editable vector source for simplified notification symbol

Android: use R.drawable.ic_stat_rhocoo for the small notification icon. Android tints this white silhouette according to system UI.
Note: Launcher images are resized from the generated concept image, not true adaptive-icon foreground/background layers.
